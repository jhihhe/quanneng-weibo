# 全能围脖

桌面版微博的阅读与信息流管理扩展。维护作者：**`@Jhih he`**。

- **阅读与主题**：5 组日夜配色、自定义文字与背景颜色、卡片排版和动效。
- **内容过滤**：关键词、正则、来源、超话等过滤规则及统计。
- **用户名单与时间线**：本地 UID 名单、名单导入导出、官方黑名单同步及时间线显示控制。
- **截图与媒体保存**：适用详情页的 PNG 截图、Markdown 导出、图片/视频/LivePhoto 保存。

## 使用

安装扩展后刷新微博，点击工具栏图标或页面右下角“围脖”，打开功能中心。模块可分别启用或关闭。请停用同类旧脚本以避免冲突。

设置与名单保存在浏览器本地。扩展与油猴脚本的存储相互独立，旧数据需手动迁移。WebDAV 默认关闭；使用时需先授权自己信任的服务器并完成配置。

当前版本：1.8.0，最低 Chrome 版本：120。商店版本正在准备发布，尚未上架。微博页面和接口变化可能影响功能；真实登录环境下的官方黑名单远程同步、WebDAV 及媒体下载仍需进一步验证。
